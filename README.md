# 💖 Интерактивный Birthday-Сайт для Амелии (29 Октября)

Индивидуальный романтический сайт-подарок в эстетике **pastel pink / coquette / scrapbook**, созданный для открытия по QR-коду со смартфона.

---

## 🌟 Что реализовано в этой версии

1. **Экран №1 — Три Сердечка с фотографиями:**
   - Сердечко Амелии (её фотографии).
   - Сердечко Тимура (твои фотографии).
   - Большое центральное сердечко «Мы вместе» (ваши совместные кадры).
   - При нажатии на каждое сердце проигрывается тихий мягкий звук `pop`, сердце сжимается/подпрыгивает, и фото плавно сменяется на следующее.
   - Чистая обрезка по форме сердца через SVG `clipPath` — фотографии отображаются идеально на любых устройствах.
   - Элегантная кнопка перехода к секретному терминалу.

2. **Экран №2 — Секретный Терминал-Дневник:**
   - Нежная розовая карточка с эффектом печатающегося текста и мигающим курсором.
   - Пин-код из 4 слотов с сердечками: **`2910`** (день рождения Амелии, также принимается `29.10`).
   - Интерактивная клавиатура с кнопками 0-9 и удалением (как на референсе из TikTok) + поддержка физической клавиатуры.
   - При правильном коде: праздничный перезвон, розовые конфетти и плавный переход к подаркам.

3. **Экран №3 — Три интерактивных подарка:**
   - Центр выбора, где Амелия сама решает, какой подарок открыть:
     - 🎁 **Подарок №1 — «Наши песни»**: Музыкальный экран с виниловой пластинкой и Spotify.
     - 💌 **Подарок №2 — «Для тебя»**: Большая раскрывающаяся открытка с личным письмом.
     - ✨ **Подарок №3 — «Наша история»**: Коллаж фотографий и режим «Смотреть нашу историю».
   - Кнопка **«Назад к подаркам»** на всех экранах позволяет вернуться и открыть другие подарки без повторного ввода пароля!

4. **Внутри подарков:**
   - **Винил и Spotify:** Вращающаяся черная виниловая пластинка с бликами дорожек и розовым яблоком `LOVER`, возможность вставить настоящий Spotify плейлист и список песен.
   - **Открытка с письмом:** Интерактивный конверт с бантиком, при клике открывающийся с конфетти. Текст поздравления на текстурированной бумаге и милый анимированный котик.
   - **Скрапбук и Видео-эдит:** Карточки воспоминаний с поляроидными рамками и режим **«Смотреть нашу историю»** — кинематографичное полноэкранное слайд-шоу с плавным зумом, сменой кадров и романтическими надписями.

5. **Фон и атмосфера:**
   - 16 всплывающих рукописных фраз на фоне (все исправлены, с восклицательными знаками и эмодзи).
   - Нежные цветы (лилия, гипсофила, сакура) и дудлы по краям экрана.
   - Переключатель звука в правом верхнем углу (включение/отключение кликов и звуков).

## 🚀 Как запустить сайт на компьютере и открыть на телефоне

### 1. Запуск в терминале:
В этой папке выполни:
```bash
npm run dev
```

В консоли появится ссылка:
```
  ➜  Local:   http://localhost:3000/
  ➜  Network: http://192.168.x.x:3000/
```

### 2. Как открыть на телефоне прямо сейчас:
1. Убедись, что твой компьютер и телефон подключены к одной и той же сети Wi-Fi.
2. Вбей в браузере телефона адрес из строки `Network:` (например, `http://192.168.1.15:3000`).
3. Сайт откроется на телефоне во всей красе!

## ✏️ Как редактировать тексты, фото и настройки

Все настройки собраны в **одном понятном файле**:
👉 **`src/content.ts`**

В нём ты можешь в любой момент изменить:
- **Пароль**: поле `secretCode: '2910'`.
- **Текст открытки**: блок `letter.paragraphs` (напиши туда свои личные слова для Амелии).
- **Всплывающие фразы**: массив `floatingPhrases`.
- **Spotify плейлист**: вставь ссылку в `music.spotifyEmbedUrl` (например, `https://open.spotify.com/embed/playlist/ВАШ_ID`).
- **Слайд-шоу**: порядок фотографий и подписи в массиве `storySlides`.
- **Фотографии**: пути в массивах `heartPhotos` и `galleryPhotos`.

## 🌐 Бесплатный хостинг (как выложить в интернет)

Чтобы сайт открывался по постоянной ссылке из любой точки мира:

### Вариант А: Vercel (Рекомендуется)
1. Зарегистрируйся на [vercel.com](https://vercel.com/) (бесплатно через GitHub).
2. Загрузи этот проект в свой GitHub-репозиторий.
3. В Vercel нажми **Add New Project**, выбери этот репозиторий и нажми **Deploy**.
4. Через 30 секунд у тебя будет готовая ссылка вида `amelia-birthday.vercel.app` с поддержкой HTTPS.

### Вариант Б: Cloudflare Pages
1. Зайди на [pages.cloudflare.com](https://pages.cloudflare.com/).
2. Сделай сборку проекта командой `npm run build` (создастся папка `dist`).
3. Перетащи папку `dist` прямо в панель Cloudflare Pages, и сайт сразу заработает!

## 📱 Как сделать красивый QR-код в виде сердца

1. Скопируй полученную ссылку на опубликованный сайт (например `https://amelia-birthday.vercel.app`).
2. Зайди на бесплатный генератор с кастомизацией QR-кодов (например, [qr-code-styling.com](https://qr-code-styling.com/) или [qrcode-monkey.com](https://www.qrcode-monkey.com/)).
3. Выбери малиново-розовый цвет (`#C77F99` или `#EAB8C8`) и вставь сердечко в центр.
4. **Важно:** обязательно проверь сканирование телефоном с расстояния перед печатью на бумажной открытке!
