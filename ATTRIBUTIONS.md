# Лицензии и авторство сторонних ресурсов (ATTRIBUTIONS.md)

В данном проекте используются следующие графические и программные библиотеки:

1. **Microsoft Fluent UI Emoji**
   - **Автор:** Microsoft Corporation
   - **Лицензия:** MIT License
   - **Репозиторий:** https://github.com/microsoft/fluentui-emoji
   - **Использование:** 3D-иллюстрации сердечек, подарка, бантика и цветка сакуры.

2. **Mega Doodles Pack**
   - **Автор:** Maria Letta (@MariaLetta)
   - **Лицензия:** Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)
   - **Репозиторий:** https://github.com/MariaLetta/mega-doodles-pack
   - **Использование:** Векторные SVG-дудлы на фоне и деталях скрапбука.

3. **Motion for React (Framer Motion)**
   - **Автор:** Motion Software Ltd
   - **Лицензия:** MIT License
   - **Использование:** Интерактивные жесты, анимации открывания открытки, переходов между экранами и всплывающих фраз.

4. **canvas-confetti**
   - **Автор:** Kiril Vatev (@catdad)
   - **Лицензия:** ISC License
   - **Использование:** Пастельно-розовые праздничные конфетти при верном вводе пароля и открытии письма.

5. **Lottie Web / Lottie React**
   - **Автор:** Airbnb / LottieFiles
   - **Лицензия:** MIT License / Community Open License
   - **Использование:** Воспроизведение векторных микро-анимаций подарка и котика.

6. **Lucide Icons**
   - **Автор:** Lucide Contributors
   - **Лицензия:** ISC License
   - **Использование:** Минималистичные иконки управления (звук, стрелки, воспроизведение).
